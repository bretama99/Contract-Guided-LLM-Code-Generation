Contract correctness:
Answer "yes" if all stated contract claims are accurate for the task.
Answer "no" if any stated claim is wrong, misleading, contradictory, or conflicts with the task.
Do not mark incorrect merely because the contracts are incomplete.
Answer "unclear" if evidence is insufficient.

Contract completeness:
Answer "yes" if the contracts cover the important intended behavior: inputs, outputs, edge cases, state properties, and invariants.
Answer "no" if they omit important requirements, constraints, edge cases, or behavioral details.
Do not mark incomplete merely because a stated claim is wrong.
Answer "unclear" if evidence is insufficient.
