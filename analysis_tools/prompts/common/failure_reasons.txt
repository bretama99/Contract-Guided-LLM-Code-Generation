Use exactly one failure reason:

- input interface/parsing mismatch: Wrong signature, argument shape, stdin parsing, unpacking, or input data structure.
- invalid input assumption: Assumes an unstated constraint, such as sorted, unique, non-empty, positive, fixed-size, rectangular, or non-null input.
- missing input case handling: Accepts the intended input form but fails on a valid edge/boundary case.
- wrong output value: Produces the right kind of result, but the computed answer is wrong.
- incomplete or extra output: Omits required results, handles only part of the input, duplicates results, or emits extra/debug output.
- wrong output format/type: Uses the wrong return-vs-print behavior, type, structure, order, precision, rounding, capitalization, spacing, or formatting.
- algorithmic logic error: Has an internal logic/control/state bug, such as off-by-one, wrong condition, bad update, bad recurrence, mutation bug, or infinite loop.
- inefficient algorithm: Mostly correct but exceeds time, memory, recursion depth, or scalability limits.
- non-executable or missing implementation: Cannot meaningfully run because of syntax errors, undefined names, missing imports, unavailable dependencies, placeholders, pass-only code, NotImplementedError, or empty implementation.
- unclear: Evidence is insufficient, or multiple categories fit equally well.
